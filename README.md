# 田园日志

《田园日志》是一款单机、纯文字、按现实日期推进的农场与牧场养成游戏。本仓库实现 V0.2 策划案中的四季循环、经营、托管、事件、关系、探索、日志和本地存档功能。

## 运行

项目没有运行时依赖，也不需要打包才能游玩。使用任意静态文件服务器打开仓库根目录，然后访问 `index.html`。例如 Node 22 环境可运行：

```sh
node scripts/serve.mjs
```

默认地址为 `http://127.0.0.1:4173`。存档只保存在当前浏览器中；“设置”页可以导出或导入单文件备份。

## 操作

- `G`：今日；`L`：日志；`/`：搜索。
- `1`—`9`：选择当前页对应项目；`Enter`：确认；`Esc`：返回今日。
- 出售动物、取消已开始工程等高风险操作需要再次确认。

## 开发与验证

使用 Node 22（仅使用内置模块）：

```sh
npm test
npm run check:content
npm run balance
npm run simulate
npm run build
npm run evidence
```

`npm run verify` 依次执行完整的自动化准出检查。构建产物位于 `dist/`，可直接由静态服务器托管；`evidence/release-manifest.json` 用逐文件 SHA-256 和发布包哈希冻结该构建。TC-052/053 的真实浏览器与辅助技术流程见 `evidence/TC-052-053-manual-protocol.md`，TC-055 的 20 人受试流程见 `evidence/TC-055-usability-protocol.md`。这些人工项完成并签署前，自动化通过不等于整体正式准出；仓库不伪造人工或受试者结果。

发布新版时，同时更新 `package.json` 与 `src/presentation/version.js` 中的版本号，再运行 `npm run build` 并完整部署 `dist/`。构建会生成 `dist/app-version.json`，并为入口脚本和样式加版本参数；已有客户端发现更高版本后会显示主动更新入口。这个入口负责保存本机存档并加载服务器上已经发布的新版，不代替服务器部署。

## 阿里云一键更新

服务器首次安装更新脚本后，以后发布最新版只需用 root 运行：

```sh
bash /root/update-farm.sh
```

脚本位于 `deploy/update-aliyun.sh`。它会从 GitHub 的 codeload 地址下载 `master`、创建独立发布目录、检查关键文件、切换 8080 端口上的 Nginx Docker 容器，并在启动检查失败时恢复旧容器。旧发布目录和旧容器不会自动删除，可用于人工回退。也可将提交哈希作为参数，发布指定版本：

```sh
bash /root/update-farm.sh 777ebd3faafa5ea0a670d554fd3ea52212ff4efa
```

黄金回放采用显式版本化：`fixtures/golden-replays-v1.json` 永久保留为内容机械化前的历史基线，当前 V0.2.0 实现由 `golden-replays-v2.json` 冻结。基线升级必须新增文件并记录首次分歧原因，不能覆盖历史文件。

## 存档兼容

当前公开存档版本为 `save_version: 1`。仓库包含一个标记为“内部预发布”的 v0→v1 相邻迁移夹具，用于验证迁移器、备份、损坏恢复和未知模块保留；它不代表曾有已发布 v0 存档。

存档采用双槽和提交指针；独立迁移前备份保存当时已提交槽的完整原始字节，并记录回退槽校验和。7 个逐日、4 个逐周和 1 个年初恢复点使用非递归压缩快照，并共享一份只保留最老有效恢复点所需窗口的压缩账本；恢复点也保存当时最多 2,000 条命令收据窗口，因此恢复后仍保留对应 `action_id` 的幂等语义。内部预发布的旧 `self_contained_v2` 恢复点仍可校验读取。

固定五年容量验收中，单状态 JSON 为 790,611 UTF-8 字节；两槽与提交指针按保守 UTF-16 口径占 3,140,246 字节，加入可导出的原始备份后共 4,610,046 / 5,242,880 字节。第 421 日单步结算实测 28.1 ms，两次槽写分别为 34.3 ms 与 53.7 ms（Node 22，本机固定夹具）；测试门槛为结算低于 2 秒、双槽与备份写入低于 3 秒。
